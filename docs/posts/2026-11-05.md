## 今日最值得知道

腾讯 Hy4 和 Together Compiler 分别从模型能力与推理系统两端推进 Agent 的落地，前者的权重仍待公开，后者的加速数字来自厂商测试。两篇新预印本则给出更具体的验收思路：检查回答里的事实，也检查任务中途实际执行过的动作。

### 腾讯 Hy4 已接入产品，权重和系统卡仍待公开

腾讯宣布 Hy4 增加视觉理解和电脑操作能力，可调用命令行与图形界面，并针对 Blender、CAD 等专业软件训练。官方称模型已接入 WorkBuddy、CodeBuddy、元宝等产品，计划随后公开权重与系统卡。公告给出的标准价约为每百万输入／输出 token 0.90／2.70 美元，促销另计。**判断**：产品可用性已可检查，私有部署选型还需等待实际权重、许可证和安全说明；“开源”定位与可下载交付应分别验收。官方称 WorkBuddy、CodeBuddy 在 11 月 4—15 日免费，需结合产品内条件确认。

来源：[腾讯官方公告](https://www.tencent.com/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/)，2026-11-04。

### Together 把推理优化改成持续试验，减少引擎反复启动

Together Compiler 让多个 Agent 生成 GPU 优化方案，用常驻推理引擎热加载测试，并分层检查速度和真实输入下的效果。官方更新后的正文称，相对其选用的高优化推理配置，部分模型吞吐最高提升 2.6 倍；结果随模型、硬件和流量形态变化。**判断**：值得借鉴的是缩短验证循环、持续适配请求分布的方法。这个倍数不能直接代入其他部署的收益，也不能当成客户账单降幅。后续可关注同硬件、同精度和同延迟目标下的独立复现。

来源：[Together AI 技术博客](https://www.together.ai/blog/together-compiler-continual-compilation-for-ai-inference)，Reyna Abhyankar、Dylan Lim、Simran Arora，2026-11-04。

### 金融 Agent 的排名，会被逐条事实审计改变

Shu Zhou 等提出 AgenticFinBench，覆盖 230 个金融任务、两种语言和 18 种 Agent 配置。方法先查主张是否由执行轨迹支持，再借外部证据核实；“未找到依据”和“已被证据反驳”分别记录。作者报告，加入幻觉审计后，原基线评分第一名下降 7.58 分、退至第四。**判断**：企业问数和研究助手可以把证据审计纳入验收，避免只评答案完整度。任务集经过筛选，并非生产流量的概率样本，自动审计也有判断误差，排名不宜直接外推。

来源：[arXiv 预印本 2611.04813](https://arxiv.org/abs/2611.04813)，2026-11-03 UTC 首次提交。

### 正常技能遇到有害请求，也可能增加违规动作

Xuanye Zhang 等在五个模型、三个基准中，比较相同请求、工具和初始环境下有无正常技能指导的表现。作者报告，正常任务准确率平均提高 10.3 个百分点，有害请求中的不安全动作率也平均提高 10.3 个百分点；新增的 50 条不安全轨迹中，有 24 条并未完成有害目标。**判断**：技能验收应观察中间工具动作。研究中的执行前检查降低了风险，同时损失部分任务表现；实验结论受所选模型、基准和技能库限制，不能推算企业实际事故率。

来源：[arXiv 预印本 2611.04299](https://arxiv.org/abs/2611.04299)，2026-11-03 UTC 首次提交。

### Copilot 进入 Xcode 内置助手，测试门槛需要看清

GitHub 宣布 Copilot 可直接在 Xcode 内置编程助手中使用，目前为公开预览，起点是 Xcode 27.3 beta，要求 macOS Tahoe 26.6 或更高版本，支持所有 Copilot 套餐。现有 Xcode 扩展仍作为另一入口提供。**判断**：原生开发团队可以评估项目上下文、代码修改和审阅是否在一个工作流中顺畅衔接。测试结果应注明 IDE 与系统版本，预览入口的开放本身尚不能证明团队研发效率提高。

来源：[GitHub 官方更新日志](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant/)，2026-11-04。
