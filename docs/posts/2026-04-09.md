## AI 资讯

**1. Anthropic 发布 Claude Mythos Preview，联合科技巨头启动 Project Glasswing 网络安全计划**（发布日期：2026年4月7日）

Anthropic 于4月7日正式宣布 Claude Mythos Preview，这是一款面向防御性网络安全领域的通用前沿大模型，以邀请制方式提供访问。Anthropic 同步启动 Project Glasswing，联合 Amazon Web Services、Apple、Broadcom、Cisco、CrowdStrike、Google、JPMorganChase、Linux Foundation、Microsoft、NVIDIA、Palo Alto Networks 等科技巨头，致力于修复关键软件基础设施中的安全漏洞。据悉，Claude Mythos Preview 在测试阶段已自主识别数千个零日漏洞，其中包括 FreeBSD 中存在17年的远程代码执行高危漏洞。模型定价为 $25/$125/百万 token（输入/输出），并通过 Claude API、Amazon Bedrock、Google Vertex AI 及 Microsoft Foundry 提供访问。Anthropic 承诺为计划参与者提供 1 亿美元的模型使用额度。

🔗 [Anthropic 官网 - Project Glasswing](https://www.anthropic.com/glasswing) | [TechCrunch 报道](https://techcrunch.com/2026/04/07/anthropic-mythos-ai-model-preview-security/)

> 💡 **AI 点评：** Mythos Preview 标志着 AI 在主动网络安全防御领域的质变——从辅助分析工具升级为能自主发现并利用漏洞的"安全专家"。对于安全团队，建议关注 Project Glasswing 的参与资格申请；对于开发者，建议评估自身基础设施是否符合参与条件，率先利用 AI 安全审计强化系统防御。

**2. Anthropic 推出 Claude Managed Agents 公测版与 ant CLI**（发布日期：2026年4月8日）

Anthropic 于4月8日同步发布两项重磅开发者工具。其一，**Claude Managed Agents** 正式进入公开测试阶段——这是一套全托管的 Agent 运行框架，提供安全沙箱环境、内置工具集和服务器推送事件（SSE）流式传输，开发者可通过 API 创建 Agent、配置容器并运行会话，所有端点均需携带 `managed-agents-2026-04-01` beta 请求头。其二，**`ant` CLI** 正式亮相，作为 Claude API 的命令行客户端，支持更快的 API 交互、与 Claude Code 的原生集成，以及通过 YAML 文件对 API 资源进行版本管理。

🔗 [Anthropic 平台发布说明](https://platform.claude.com/docs/en/release-notes/overview)

> 💡 **AI 点评：** Claude Managed Agents 的托管沙箱设计大幅降低了 Agent 基础设施的运维门槛，适合快速原型验证的团队。建议开发者尽早接入公测，重点测试长任务的状态持久性和异常恢复能力；`ant` CLI 则特别适合在 CI/CD 流水线中集成 Claude API 调用，值得纳入自动化工作流。

## 前端资讯

**1. Vite 8.0 正式发布：Rolldown 引擎驱动，构建速度提升 10-30x**（发布日期：2026年3月12日）

Vite 8.0 是 Vite 自 v2 以来最重大的架构升级——使用 Rolldown（Rust 编写的统一打包器）替代此前的 esbuild + Rollup 双引擎架构，带来高达 10-30 倍的构建速度提升，同时保持与现有插件生态的完整兼容性。新功能亮点包括：统一打包器解锁了全量打包模式、更灵活的代码分割、模块级持久缓存和 Module Federation 支持；内置 **Vite Devtools**（调试与分析工具）；Wasm SSR 支持（`.wasm?init` 导入在 SSR 环境中正常工作）；浏览器控制台日志转发至开发服务器终端（对 AI 编码 Agent 尤其有用）。与此同时，`@vitejs/plugin-react v6` 同步发布，使用 Oxc 进行 React Refresh 转换，移除了 Babel 依赖。

🔗 [Vite 官方博客](https://vite.dev/blog/announcing-vite8)

> 💡 **AI 点评：** Rolldown 的引入是前端工具链近年来最重要的性能突破，对大型 monorepo 项目的收益尤为显著。建议项目组尽快测试迁移，关注插件兼容性（尤其是自定义 Rollup 插件）；浏览器日志转发功能对 AI Agent 辅助调试场景是加分项，值得在 CI 流程中启用。

**1. DeepSeek 网页端上线"快速模式"与"专家模式"，V4 呼之欲出**（发布日期：2026年4月8日）

DeepSeek 于4月8日悄然更新网页端界面，在输入框上方新增"快速模式"与"专家模式"双模式切换。**快速模式**面向日常对话，支持图片和文件中的文字识别，响应速度快；**专家模式**专攻长程复杂问题，但暂不支持文件上传和多模态功能，高峰期需排队等待。两种模式均搭载知识库截至2025年5月、上下文窗口 1M tokens 的模型。目前该更新处于灰度测试阶段。业界普遍猜测这是 DeepSeek V4 正式发布的前奏——据此前泄露信息，V4 Lite 版将达 200B 参数，原生支持图片、视频和文本的多模态生成，并将深度适配国产芯片。

🔗 [知乎讨论](https://www.zhihu.com/question/2024876426596291384) | [新浪财经报道](https://finance.sina.com.cn/tech/2026-04-08/doc-inhttxke2894022.shtml)

> 💡 **AI 点评：** "快速/专家"双模式路由是一种务实的算力调度策略——用轻量模型承接高频简单查询，将深度推理资源集中于复杂任务。开发者可关注其 API 是否同步开放模式选择参数；若 V4 如期在本月发布，建议团队提前评估其多模态能力与现有工作流的整合方案。
