**2. Google Gemini Deep Research API 公测上线：开发者可嵌入高级研究 Agent 能力**（发布日期：2026年4月1日）

Google 通过新发布的 **Interactions API** 将 Gemini Deep Research Agent 以公测形式开放给开发者，可通过 Google AI Studio 获取 API Key 直接调用。核心能力包括：文档分析（PDF、CSV、Docs）+ 公开网页数据检索、可定制的研究报告结构、精细引用溯源、JSON Schema 结构化输出。在基准测试中，Deep Research 在 Humanity's Last Exam（HLE）完整集上达到 **46.4%**，DeepSearchQA 达 **66.1%**，BrowseComp 达 **59.2%**。Google 同步开源了 DeepSearchQA 基准，包含 900 个跨 17 个学科的手工因果链任务。

🔗 [Google 官方博客](https://blog.google/technology/developers/deep-research-agent-gemini-api/) | [Google Developers Blog](https://developers.googleblog.com/building-agents-with-the-adk-and-the-new-interactions-api/)

> 💡 **AI 点评：** Deep Research API 的开放意味着开发者可以构建"自动深度调研"功能而无需自行拼装 RAG 管道。建议关注其与 Agent Development Kit（ADK）和 A2A 协议的集成——这为构建多 Agent 研究系统提供了标准化路径。注意 API 目前仍为公测，生产环境使用需评估配额限制。
