## 今日最值得知道

Google 发布 Gemini Decisions API，为多模态分类和路由提供独立接口。AlphaGenome 2 提高了细胞类型层面的变异筛选召回率，适合用来挑选待验证的候选。Databricks 把企业指标定义和权限带进持续任务，Anthropic 路演披露了拟议发行条件。

### 本次新增 · Gemini Decisions API 将多模态判定从文本生成中拆出

Google 发布 Gemini Decision 1，一次调用可就同一份文本、图像、音频、视频或 PDF 提出最多 1,000 个封闭问题，返回选项分数或概率。官方定价为每百万输入 token 0.10 美元，输出免费，共享输入每次请求只计费一次。官方给出的端到端延迟为 150–250 毫秒，测量覆盖不超过 16K token 的输入及每次 1–100 个问题。**判断**　可先用于路由或批量分类，上线前按真实负载验证置信度校准和尾延迟。

来源：[Google 发布公告](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)，2026-11-11（公告日期）。

### 本次新增 · AlphaGenome 2 在细胞类型层面筛选调控变异

Google DeepMind 发布 AlphaGenome 2，将 DNA 序列与细胞状态一起输入模型，新样本可用单细胞表达数据作为条件，无需重训。技术报告显示，在 TenK10K 的 28 类免疫细胞上，精确率为 90% 时，单细胞基因表达相关变异的召回率由经单细胞数据微调的一代模型的 16% 升至 30%。**判断**　可用来给待验证变异排序。疾病状态的训练覆盖仍有限，预测需要实验验证。API 已向非商业研究开放，商业研究为私有预览。

来源：[Google DeepMind 公告](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)、[技术报告](https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/alphagenome-2.pdf)，Adam Gayoso、Natasha Latysheva 等，2026-11-11。

### Anthropic 启动路演，公开发行和同期私募须分开计算

Anthropic 拟公开发行 8.25 亿股 A 类普通股，指示价为每股 70 至 78 美元，其中约 8.01 亿股由公司发行，其余由原股东出售。修订招股书按中点价估算，公开发行与同期私募合计净所得约 846 亿美元，假设承销商未行使增购权。文件将算力和基础设施列入资金用途，也列有营运支出等用途。**判断**　评估这笔融资对算力投入的影响，要等最终定价和实际净所得落定，再看资本开支披露。

来源：[Anthropic 路演公告](https://www.anthropic.com/news/roadshow-launch)、[提交至美国 SEC 的 S-1/A](https://www.sec.gov/Archives/edgar/data/2130357/000162828026072484/anthropicpbc-sx1ax2.htm)，2026-11-10（美国日期）。

### 本次新增 · Databricks Genie 把企业指标和权限带进持续任务

Databricks 发布第二代 Genie，支持持续跟进任务，并让外部 Agent 通过 MCP 使用企业指标定义与检索。官方与 Turing 在一个虚构电力公司的 Databricks 工作区测试，每题各跑五次，Genie 通过率为 91%，两个匿名对照为 45% 和 58%。Genie 原生运行并使用已积累的上下文，对照通过工具接入且未使用 Genie MCP。**判断**　企业选型时，可先在同一套指标口径和权限下对照，再核查长任务的审批和审计记录。

来源：[Databricks 产品公告](https://www.databricks.com/blog/new-genie-autonomous-ai-complex-enterprise-work)、[评测方法与案例](https://www.databricks.com/blog/genie-genie-ontology-delivers-16-accuracy-less-half-tokens)，2026-11-11。

### Adobe 预览本地 MCP，第三方 Agent 可以改原生工程文件

Adobe 在迈阿密海滩举行的 MAX 大会上预览本地 MCP 集成，覆盖 Photoshop、Illustrator、Premiere 和 After Effects。官方称，第三方 Agent 可修改原生工程文件并保留可继续编辑的图层、序列和合成。同期 Creative Agent 扩展到多款 Creative Cloud 应用，Firefly 助手在测试版中加入计划模式与模型选择。**判断**　创意团队可以交接一份真实工程，检查素材引用、修改范围和回滚，再判断这种接入能否用于多人协作。四款工具的 MCP 集成目前为预览。

来源：[Adobe MAX 官方公告](https://news.adobe.com/news/2026/11/adobe-powers-new-era-of-creativity)，2026-11-10（大会当地日期）。

### NVIDIA 将 AI 物料清单纳入部分 GPU 集群的默认配置

NVIDIA 把 Google 开源的 k8s-aibom 纳入 AI Cluster Runtime。两套面向 GKE 上 H100 推理的预置配置默认启用，其他 GKE 配置可选择开启。该组件为能识别的 Kubernetes 工作负载记录模型、镜像和推理运行时，并标注证据与置信级别。清单在 Pod 启动前也可能显示就绪。**判断**　排查集群中同一镜像标签对应不同版本时，可用清单追溯已解析的制品，再结合 Pod 状态和服务探测确认请求确实由目标版本处理。

来源：[NVIDIA 技术博客](https://developer.nvidia.com/blog/validating-gpu-platforms-with-runtime-ai-inventory-via-the-nvidia-dsx-ai-factory/)、[Google 开源项目](https://github.com/GoogleCloudPlatform/k8s-aibom)，Mark Chmarny，2026-11-11。

### 科研 Agent 比较竞争解释，在同等验证预算下回答了更多问题

Ziang Liu 等人的 Contrastive Discovery 让 Agent 先列出互斥的候选解释，再用同一份证据更新对各解释的支持度。作者在材料、天文等六个表格数据集上报告，相同的 200 次验证预算下，达到支持阈值的问题数比按单一假设的意外程度排序多 67%。在 38 名专家参与、覆盖 60 个问题的盲评中，专家对模型已判定问题的解释同意率为 78.4%。实验只使用一种基础 Agent，观测数据提供统计线索，候选集漏掉证据支持的解释也会导致误判。**判断**　让 Agent 列出替代解释，并保留“证据不足”的选项，有助于复核结果。

来源：[arXiv 预印本 2611.14514](https://arxiv.org/abs/2611.14514)、[方法、实验与局限](https://arxiv.org/html/2611.14514v1)，2026-11-10 UTC 首次提交，北京时间 11 月 11 日，11 月 11 日列表公布，v1。

### 本次新增 · AutoScaffold 随训练进展调整提示，验证成本也要计入

Zijian Zhang 等人让固定的教师模型查看学生轨迹，提出任务策略或个别提示。部署新策略前先在留出的任务上验证，学生进步后降低提示频率，最终评测撤掉提示。作者报告，Qwen2.5-1.5B-Instruct 在 ALFWorld 上从 GiGPO 对照的 86.7% 升至 93.9%，省去策略验证的消融降至 79.8%。**判断**　引入提示时应同时看独立完成率和验证耗时。附录所报教师 API 费用之外，还有学生验证占用的 GPU 时间。

来源：[arXiv 预印本 2611.14515](https://arxiv.org/abs/2611.14515)、[方法、实验与成本](https://arxiv.org/html/2611.14515v1)，2026-11-10 UTC 首次提交，北京时间 11 月 11 日，11 月 11 日列表公布，v1。
