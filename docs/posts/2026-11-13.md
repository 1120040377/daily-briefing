## 今日最值得知道

Gemini 4 Hydrogen 把百万 token 上下文带到更低的标准费率，Claude Managed Agents 则把可自托管的范围从沙箱扩展到编排服务。两项工程研究分别测出了训练故障的漏检边界和长上下文索引的提速条件。同步辐射实验也展示了如何从对话记录追溯 Agent 参与的实验决策。

### Gemini 4 Hydrogen 开放，百万 token 上下文采用统一费率

Google 发布面向编码与日常 Agent 任务的 Gemini 4 Hydrogen，接入 Gemini API、AI Studio 和 Gemini 应用，并在 Antigravity 向付费 Pro、Ultra 用户提供。官方定价为每百万输入和输出 token 1.50 和 7.50 美元，整个百万 token 上下文采用同一费率。开发者可在低、中、高和最高四档推理强度间选择。模型卡提示，高档位可能消耗更多 token，仍可能出现幻觉或超时。**判断**　评估能否接手日常执行时，按同一批任务比较完成率、重试次数和总账单。

来源：[Google 发布公告](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)、[Google DeepMind 模型卡](https://deepmind.google/models/model-cards/gemini-4-hydrogen/)，2026-11-12。

### Claude Managed Agents 私测把编排和会话迁入客户环境

Anthropic 开放自托管 Managed Agents 私测。先前可自托管工具沙箱，本次还可把编排服务、会话历史和凭据放在自有云或本地环境。企业负责运行服务端、数据库和执行工具的工作进程，可把模型请求发往 Anthropic、支持的云服务或自有网关。官方架构把凭据留在沙箱之外，由代理为受支持的工具请求注入。会话历史存入企业自己的数据库，团队仍可使用托管版的核心 API。**判断**　部署前应画清模型请求的出站路径，并验证凭据注入范围、会话恢复和升级责任。

来源：[Anthropic 发布公告](https://claude.com/fr/resources/articles/self-hosted-claude-managed-agents)、[自托管文档](https://platform.claude.com/docs/fr/managed-agents/self-hosted)，2026-11-12。

### AWS 在训练环节复算微批次，拦截部分静默错误

AWS 给出在 SageMaker HyperPod 的 PyTorch DDP 作业中加入梯度检查、跨节点复算与权重指纹核验的方法。官方用三台和四台各配八张 H100 的实例训练约 9.53 亿参数模型，并注入模拟故障。保存前比对权重阻止了一次位翻转写入检查点，但默认算子审计漏过一个只影响反向梯度的案例。**判断**　需要在真实并行配置上演练故障注入和回滚，并衡量复算开销。故障可能早于告警指向的窗口，选择回滚点时还要核查上一次通过审计的记录。

来源：[AWS 技术文章](https://aws.amazon.com/blogs/machine-learning/detecting-and-recovering-from-silent-data-corruption-on-amazon-sagemaker-hyperpod/)，Siddharth Senger 等，2026-11-11。

### ADIndex 复用稀疏注意力的候选集合，收益随上下文长度变化

Jin-Fei Qi 等人让同组查询共享候选 token，再对每条查询重排，并按层设置候选预算。作者在 B300 上用 SGLang 评测 DeepSeek-V3.2 和 GLM-5.1。对 DeepSeek-V3.2，相较原始 DSA，128K 上下文端到端速度为 1.54 倍，RULER 分数低 0.35 个百分点。16K 时速度只有基线的 0.86 倍。短输入中，建立共享候选集合的开销可能抵消少扫上下文的收益。**判断**　先按真实请求的长度分布划定启用阈值，同时验收长文检索和推理质量。

来源：[arXiv 预印本 2611.12956](https://arxiv.org/abs/2611.12956)、[方法与实验](https://arxiv.org/html/2611.12956v1)，2026-11-07 UTC 首次提交，北京时间同日，11 月 11 日列表公布，v1。

### 同步辐射实验用对话日志追溯谁提出并修正测量决策

Gunik Luthra 等人用 Claude Code 协调测量、散射分析和高斯过程选点，在科学家设定目标下完成三次同步辐射实验，共逾 50 小时。研究把对话、代码改动与实验结果相连，并用人工抽检和两种模型复核归因。作者估计，约 42%–52% 的抽样决策链参考了其他参与者的输入，改用两个模型都确认的链条后为 37%–46%。实验只覆盖一条束线、一位科学家和一套平台，归因标签也有不确定性。**判断**　接入仪器时，应把测量依据和纠偏记录与结果一并保存。

来源：[arXiv 预印本 2611.12933](https://arxiv.org/abs/2611.12933)、[方法、实验与局限](https://arxiv.org/html/2611.12933v1)，2026-11-06 UTC 首次提交，北京时间同日，11 月 11 日列表公布，v1。
