**1. Vite+ 发布：VoidZero 打造 JavaScript 统一工具链，对标 Rust 的 Cargo**（发布日期：2026年4月）

Vite 作者尤雨溪（Evan You）创办的 **VoidZero** 正式发布 **Vite+**，定位为企业级 JavaScript 统一开发工具包，目标是"成为 JavaScript 生态的 Cargo"。Vite+ 整合了 Vite 8（Rolldown 打包引擎）、Oxc（Rust 编写的 lint/format/parse/transpile/minify 工具链）、以及新的 Monorepo 管理和依赖缓存层，提供开箱即用的一站式开发体验。实测数据显示，Excalidraw 构建时间从 22.9 秒降至 1.4 秒（**16 倍提升**），内存占用降低最高 **100 倍**。

🔗 [VoidZero 公告](https://voidzero.dev/posts/announcing-rolldown-vite) | [The New Stack 报道](https://thenewstack.io/vite-aims-to-end-javascripts-fragmented-tooling-nightmare/)

> 💡 **AI 点评：** Vite+ 的"统一工具链"理念如果成功，将极大简化前端项目的工具链配置——不再需要分别管理 ESLint、Prettier、TypeScript、Bundler 等独立工具。建议关注 Vite+ 的 Monorepo 支持成熟度，对于中大型项目，统一工具链带来的一致性和性能收益尤为显著。
