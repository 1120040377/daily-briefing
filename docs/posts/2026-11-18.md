## 今日最值得知道

GPT-6.2 已开放，Gemini Tasks 则开始向六国用户免费提供后台任务能力，付款等高级功能先在美国落地。模型成本之外，今天更值得观察的是任务如何验收、权限如何撤回，以及保存的技能能否经得住独立复测。新预印本显示，小样本微调可以更好地保留知识，也可能牺牲部分指令遵循表现。

### 本次新增 · GPT-6.2 已开放，工具调用接入要复查

OpenAI 发布 GPT-6.2 Astra 与 Sol，向 ChatGPT Work、Codex 的 Plus、Pro、Enterprise 和 Edu 用户提供，企业与教育工作区还受管理员设置约束。Astra 标准 API 每百万输入、缓存输入、输出 token 分别为 8、0.40、40 美元；普通输入和输出较 GPT-6 Astra 便宜 20%。两者支持 Chat Completions 和 Responses，但工具调用要求 Responses。**判断**　迁移预算应同时记录整次任务的输出量、缓存命中和重试，先验证旧工具循环能否正常执行。

OpenAI · 2026-11-17（原始发布） · [发布与定价](https://openai.com/index/introducing-gpt-6-2-astra-sol/) · [API 变更记录](https://developers.openai.com/api/docs/changelog)

### 本次新增 · Gemini Tasks 免费扩展至六国，付款仍需逐次批准

Google 将基于 Gemini 4 Hydrogen 的 Tasks 免费逐步推向美国、日本、韩国、加拿大、澳大利亚和印度，支持后台多步任务与定期例行任务。电话、短信、邮件和付款等高级能力先在美国推出。发布记录写明，Google Pay 结账会先提交逐项摘要，用户明确点击并完成设备批准后才付款，适用美国成年个人账户。**判断**　免费入口会扩大个人 Agent 的试用面，验收重点可放在预算上限、任务中途修改与最终交付回执，尚不能据此推断复杂任务的可靠完成率。

Josh Woodward（Google Labs、Gemini app 与 AI Studio 副总裁） · 2026-11-17 · [原始公告](https://blog.google/innovation-and-ai/products/gemini-app/tasks-in-gemini-free-new-features/) · [功能和地区条件](https://gemini.google/us/release-notes/?hl=en)

### 本次新增 · MAI Code 2 进入 Copilot，低成本比较包含五折促销

微软发布 MAI Code 2 与 Flash，两者已在 GitHub Copilot 可用，Flash 在 Foundry 为限量预览。官方称，在 DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas 和 FrontierCode 1.1 的平均结果中，Code 2 达到 GPT-6.1 Sol 的 98% 表现，成本约为其 40%。脚注明确，比较使用最高推理档，Code 2 成本按五折促销价计算。**判断**　常见修复和多文件改动可重新测算任务成本，采购预算还需核对优惠结束后的报价和长任务完成率。

Microsoft AI · 2026-11-17 · [模型公告与评测条件](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)

### 本次新增 · SenseNova-Loop 正式开放，用重复计算扩展九十亿参数模型

商汤发布 SenseNova-Loop-9B 正式版权重与代码，沿用预览版的共享权重循环结构，支持图文输入、文本输出。官方配置有 32 组解码层权重，一次前向执行 56 层计算；四位量化权重约占 4.9 GB，运行还需 KV 缓存和其他显存。模型卡标注 Apache 2.0，下载文件需接受访问条件。**判断**　低显存团队可测试这类参数复用方案，重点记录端到端延迟和长任务完成率。当前部署说明仍部分沿用预览版，并要求专门适配的推理引擎版本。

SenseNova 团队 · 2026-11-17（正式版发布） · [模型卡、权重和限制](https://huggingface.co/sensenova/SenseNova-Loop-9B) · [官方代码与部署说明](https://github.com/OpenSenseNova/SenseNova-Loop)

### 本次新增 · Work IQ 让外部 Agent 获取企业上下文，记忆仍在预览

微软宣布 Microsoft IQ 企业上下文管理平台。Work IQ 的 Retrieve 已正式可用，一次调用返回按权限裁剪的 Microsoft 365 内容和联合连接器数据；长任务、Agent 间协作及面向 ChatGPT、Claude 的插件也已正式可用。记忆、Office 文件创建编辑与带人工批准的策略治理仍为公开预览。**判断**　试点可先检查同一请求在不同员工身份下返回哪些证据，再测试权限撤回后长任务能否及时停止访问。

Yitzhak Kesselman（微软 Microsoft IQ 副总裁） · 2026-11-17 · [产品公告及可用范围](https://azure.microsoft.com/en-us/blog/introducing-the-new-microsoft-iq-putting-your-organizations-intelligence-to-work-in-every-agent/)

### 本次新增 · Agent 自我改进的验证分数上涨，独立复测可能不再成立

Yuanhao Zeng 等在冻结权重的 Agent 上比较七种提示、记忆、技能或执行框架优化方法，把候选质量波动和评测噪声分开测量。作者对 Terminal-Bench 中 SkillOpt-Lite、GEPA 各八次演化过程重测，每份产物每题跑八次。循环内显示提高 6.9–9.0 个百分点，独立重测的变化却在 −3.2 至 +0.4 个百分点。**判断**　保存技能前可加入重复验收和独立复测；该轨迹实验限于两个方法、两个模型，结论暂不能覆盖更新模型权重的强化学习。

Yuanhao Zeng 等 · arXiv 预印本 · 2026-11-18（北京时间首次提交，同日列表公布，v1） · [论文记录](https://arxiv.org/abs/2611.23068) · [实验与局限](https://arxiv.org/html/2611.23068v1)

### 本次新增 · 微调时对齐基座的高温分布，可缓解小样本遗忘

Giannis Daras 等提出 Ambient SFT，在监督微调中加入与冻结基座模型的高温输出分布对齐，约束模型保留原有知识。作者用约 2.1 万条 Dolci 指令训练 Qwen3-4B，MATH 得分由普通 SFT 的 36.4 升至 42.2，IFEval 则从 76.3 降至 71.0；常用配置同等步数约慢 10%。**判断**　数据稀缺团队可同时验收知识保留和指令遵循。研究仍在进行，温度选择与数据来源会影响取舍，完整训练成本也需重测。

Giannis Daras 等 · arXiv 预印本，作者标注工作进行中 · 2026-11-18（北京时间首次提交，同日列表公布，v1） · [论文记录](https://arxiv.org/abs/2611.23229) · [方法、实验与开销](https://arxiv.org/html/2611.23229v1)

### 本次新增 · 科研 Agent 的 95% 区间，可能频繁漏掉真值

劳伦斯利弗莫尔国家实验室的 Brian T. Weston 等发布 SciResearch-Eval，让 Agent 自行设计加热实验，并使用可能缺失物理效应的模拟器估计材料参数。作者在 93 道留出题、九个模型上报告，模拟器物理错误时，多个模型自报的 95% 区间实际覆盖率仅为 20%–62%，GPT-6 Astra 为 94%，Claude Fable 5.2 为 99%。**判断**　科研验收值得加入错误模拟器和校准测试。主比较采用各家默认推理档，研究限于热传导，未收集人类基线。
