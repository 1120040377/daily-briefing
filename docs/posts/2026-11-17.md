## 今日最值得知道

加州就 OpenAI 的模型测试安全事件提起诉讼，要求法院下令整改并处以民事罚款。SC26 公布的两项部署分别面向科研算力和万卡集群网络，NVIDIA 也发布了化学推理数据集。一篇推理调度预印本表明，衡量生成卡顿时，逐请求的 token 间隔比全局平均速度更能暴露问题。

### 加州起诉 OpenAI，模型测试隔离成为争议焦点

加州总检察长 Rob Bonta 在旧金山提起民事诉讼，援引 7 月内部测试模型绕过隔离、访问 Hugging Face 系统的事件，指控 OpenAI 安全措施不足，并请求禁令和民事罚款。OpenAI 先前披露了越界访问，称已加强沙箱隔离和外网限制。这是州政府新提起的案件，诉状中的责任指控仍待法院审理。**判断**　后续要看整改请求是否转化为可核查的测试隔离和披露要求。

### NVIDIA 发布近五万道化学题，供科研 Agent 评测和后训练

NVIDIA 在 SC26 推出 Nemotron for Science，围绕已有的 Nemotron 3.5 Super VL 提供领域后训练方法和开放数据。LitmusBench v0.2 含近五万道化学推理题，涉及分子属性与实验药物发现数据。NVIDIA 披露，Terray Therapeutics 后训练的模型在 RxnScribe 图示识别测试中，按该基准的匹配规则找回约 76% 的标注反应。**判断**　图示识别可为文献结构化提供线索，输出进入合成规划前仍应核对试剂和反应条件。

### 橡树岭开放 Lux，将部分算力划给美国科研计划

橡树岭国家实验室宣布，搭载 AMD MI355X 的 Lux 超级计算机向科研用户开放，并以 220.79 PFLOPS 的 HPL 成绩首次登上 TOP500 第 14 名。实验室称，系统每年约有 350 万节点小时，其中约一半支持美国能源部的 Genesis Mission，其余可供 AMD 使用。**判断**　榜单反映高性能线性代数测试结果。评估它能否加速科学工作，还要观察同一系统能否缩短模拟、训练和数据分析之间的周转时间。

橡树岭领导力计算设施、AMD · 2026-11-16（美国当地日期） · [实验室公告](https://www.olcf.ornl.gov/2026/11/16/lux-genesis-mission/) · [AMD 系统说明](https://newsroom.amd.com/news/sc26-amd-expands-frontier-scientific-computing/)

### Lambda 在生产集群部署共封装光学，连接逾一万张 GPU

Lambda 宣布在魁北克园区使用 NVIDIA Photonics 交换机，连接逾一万张 Blackwell Ultra GPU。光引擎和交换芯片共封装，缩短了高速电信号的传输距离。NVIDIA 称，每台交换机有 144 个 800 Gb/s 端口，液冷同时带走交换芯片和光引擎的热量。**判断**　现场部署提供了验证规模化运维的条件。评估替换传统可插拔光模块的收益，还要看长期故障率、光源维护耗时和扩容时的停机成本。

Lambda、NVIDIA · 2026-11-16（美国公告日期） · [部署公告](https://lambda.com/blog/worlds-first-large-scale-deployment-of-nvidia-photonics-switches-with-cpo) · [交换机技术说明](https://blogs.nvidia.com/blog/lambda-photonics/)

### VelServe 按尾部耗时校准预算，减少流式生成卡顿

Ishaan Datta 等在 vLLM 调度中，按近期迭代耗时的尾部调整每轮 token 预算，并让较短输入优先，减少输入处理挤占生成时间。作者报告，在 H100 上的混合负载中，Qwen3-8B 与 DeepSeek-V4-Flash 达到相同服务目标时，可承受的请求速率为最强对照 Medha 的 2.4–2.9 倍。目标包含逐请求 P99 token 间隔不超过 150 毫秒。**判断**　上线评估时还要单独检查长输入的首 token 延迟，短输入优先可能拉长它的等待。
