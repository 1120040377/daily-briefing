## 前端资讯

**1. Next.js 高危 DoS 漏洞 CVE-2026-23869 披露，影响 13~16 全系版本**（发布日期：2026年4月8日）

React Server Components 中被披露一个高危拒绝服务漏洞（CVE-2026-23869，CVSS 7.5），攻击者可通过构造特殊 HTTP 请求发送至任意 App Router Server Function 端点，在反序列化阶段触发 CPU 过载，最终导致服务崩溃或内存溢出。该漏洞影响 Next.js 13.x、14.x、15.x 和 16.x 所有使用 App Router 的项目。Vercel 已向其 WAF 部署自动防护规则，免费保护所有托管在 Vercel 平台的项目，但强调 WAF 不能替代版本升级，建议所有用户立即升级到已修复版本。

🔗 [Vercel 变更日志（CVE-2026-23869）](https://vercel.com/changelog/summary-of-cve-2026-23869) | [Next.js Releases](https://github.com/vercel/next.js/releases)

> 💡 **AI 点评：** 使用 App Router 的所有 Next.js 项目均受影响，应立即执行 `npm update next` 并锁定修复版本。自托管部署（非 Vercel 平台）无法享受 WAF 自动防护，风险敞口更大，需优先处理。建议在 CI pipeline 中加入依赖安全扫描（`npm audit`），将类似漏洞的响应从被动转为主动。
