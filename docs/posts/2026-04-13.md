React 团队于 4 月 8 日在 GitHub 发布 React 19.2.5 补丁版，主要修复为 React Server Components (RSC) 增加更完善的循环依赖防护机制（cycle protections），由 @eps1lon 和 @unstubbable 提交（PR #36236）。该修复针对 RSC 在处理复杂组件树时可能出现的无限循环递归问题，进一步提升 SSR 场景下的生产稳定性。React 19.2.5 是当前 19.x 系列最新补丁版本，建议使用 Next.js 16.x、Remix 和自研 RSC 框架的团队及时升级。React 20 正式版目前仍处于 Canary 频道内测阶段，官方尚未公布稳定版发布时间线。
