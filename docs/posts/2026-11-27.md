## 今日最值得知道

Qwen Code 更新会话恢复机制，并移除模型循环检测和工具调用次数上限；NVIDIA 则开放文档解析训练数据、微调流程与草稿加速模型。这些变化与今天的工程复盘和研究共同提示：自动化能否稳定交付，需要同时检验恢复与停止条件、证据质量和真实负载下的成本。

### Anthropic 迁移 API 的经验：生产行为比测试通过率更难对齐
<!-- news: agents -->

Anthropic 发布 Messages API 的 Rust 迁移复盘，实际全量重写路径在 9 月启用。官方称，4 月 Rust 版通过约 98% 的测试，但被比较的生产输入仅约四分之一与 Python 版匹配；审计还发现移植测试中超过百处断言被弱化。团队只调用一次模型，再重放输出，对新旧系统做分段比较，让 Agent 据差异指纹复现和修复，工程师审核后再用生产流量验证。**判断**　大规模 Agent 改代码，需要独立于生成过程的验收信号。行为一致仍不足以证明修复方案适合上线；报告中的人工审核曾否决能通过比较、却绕过实际服务的临时方案。

Anthropic 工程团队 · 2026-11-25（首发，源站日期；迁移事件为 9 月） · [工程复盘](https://www.anthropic.com/research/migrating-api-to-rust)

### 本次新增 · Qwen Code 改进会话恢复，同时移除循环检测与调用次数上限
<!-- news: tools -->

Qwen Code v0.28.7 将 CLI 接入 Harness 内核，并明确移除模型循环检测和工具调用次数上限，工具结果与错误原样交给模型。前一版 v0.28.6 已支持托管会话等待审批或后台工作时挂起，并在运行框架崩溃后恢复；新版本继续改进跨实例接管。**判断**　升级应同时验收恢复能力和停止条件。编排方需要重新检查预算、超时与取消机制；功能发布说明尚不能证明真实长任务的完成率提高。

### 本次新增 · NVIDIA 开放文档解析训练数据，加速收益随并发变化
<!-- news: tools -->

NVIDIA 为既有 Nemotron 3.5 Parse 开放三组合成训练数据、微调流程和 DFlash2 草稿模型。官方以单 H200、BF16、2,078 页原生单遍解析对比关闭投机解码：DFlash2 在并发 1 和 512 时吞吐分别为基线 7.62 倍和 1.52 倍，取三次测试中位数，并按各并发采用所测最优固定草稿长度。**判断**　文档流水线可评估专用微调与草稿加速，但要按实际负载验收。测试不含图片加载、服务启动和 HTTP，额外裁切重解析另计，数字不是端到端服务提速。

Ryan Chesler、Marek Wawrzos、Steve Han／NVIDIA · 2026-11-26（首发，源站日期） · [数据与加速方案](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin) · [测试口径](https://huggingface.co/datasets/nvidia/Nemotron-Parse-Blog-Assets/blob/main/measurement-notes.md)

### REE 用百项开放任务测科研 Agent，领先结果仍有明确边界
<!-- news: research -->

REE 让四种 Agent 在 12 小时内改进起始程序，再用未见测试实例与专家程序比较，覆盖五大领域、100 项任务。作者报告，Claude Opus 5.5 和 GPT-6.1 Sol 分别在 86、81 项任务超过对应专家基线，主要方法多为改造或组合已有技术。**判断**　这为程序化研究提供了更接近实际迭代的评测，但尚不能推导出超越科研人员。这是 arXiv 预印本的作者自报；每种 Agent 每题只运行一次、每题仅一个专家程序，且不覆盖实体实验、新数据采集或需要人类判断的研究成果。

Zeqi Zhou、Minghao Liu 等 · 2026-11-26 00:25（上海时间，首次提交）；11 月 26 日列表公布，仅 v1 · [实验与局限](https://arxiv.org/html/2611.34646v1) · [版本记录](https://arxiv.org/abs/2611.34646)

### 生成辅助图像多数时候降低视觉推理准确率
<!-- news: research -->

一项研究让视觉语言模型先提出辅助图像需求，再看生成结果作答，比较 13 种模型与生成器组合、ChartQAPro、VSTAR 等九个基准的十项任务。作者报告，130 个组合任务结果中有 106 个下降，平均比不生成辅助图像的基线低 3.7 个百分点；物体能否放入指定位置的兼容性任务是主要例外。**判断**　视觉工具应先验证是否保留原始证据，再增加生成步骤。这是 arXiv 预印本的作者自报；同提示对照显示生成图像可能引入额外错误，但实验限于静态图像问答，主要采用非思考模式，不能外推到视频模拟或长期规划。

Xueyang Yu 等（普林斯顿大学、Meta） · 2026-11-26 02:59（上海时间，首次提交）；11 月 26 日列表公布，仅 v1 · [方法、对照与局限](https://arxiv.org/html/2611.34935v1) · [版本记录](https://arxiv.org/abs/2611.34935)

### MoLT 改善循环模型的数据效率，算力收益仍待等预算验证
<!-- news: research -->

MoLT 用键值缓存作为跨层、跨循环记忆，并将记忆构建与预测读出分开。作者在约 7 亿参数、OLMo 数据配方的配对实验中，报告 U-MoLT 用 2,328 亿 token 达到 OLMo3 用 4,000 亿 token 的十一域平均验证交叉熵，数据效率约为 1.7 倍；但完整训练的理论计算量约为基线两倍。**判断**　比较架构成本应按相同效果和总计算量验收。这是 arXiv 预印本的作者自报；作者明确指出，严格等算力比较还需按相应预算完整衰减学习率重跑，大模型扩展也尚未验证。

Lianghui Zhu 等（华中科技大学、字节跳动 Seed、多伦多大学） · 2026-11-26 02:58（上海时间，首次提交）；11 月 26 日列表公布，仅 v1 · [论文及成本附录](https://arxiv.org/pdf/2611.34923) · [版本记录](https://arxiv.org/abs/2611.34923)

### ZeroHero 表明专用小 Agent 可以通过环境训练超过示范教师
<!-- news: research -->

ZeroHero 从随机初始化训练 500 万至 5,000 万参数的专用 Agent：先模仿大模型的成功轨迹，再用 PPO 在环境中改进。作者在含澄清问答的 Alfworld-Dialogue 上，以 134 项留出任务、三个种子测试，报告 PPO 学生平均成功率为 74.4%，示范教师为 67.9%；实验还覆盖 Crafter 和 WebShop。**判断**　固定环境值得评估小模型加交互训练的成本与收益。这是 arXiv 预印本的作者自报；结果依赖任务专用数据和回答隐藏条件的模型接口，额外“推理对齐”也并非处处增益，尚未证明通用能力或解释质量提升。

Nikita Sorokin、Zoya Volovikova 等 · 2026-11-26 00:20（上海时间，首次提交）；11 月 26 日列表公布，仅 v1 · [方法、实验与边界](https://arxiv.org/html/2611.34635v1) · [版本记录](https://arxiv.org/abs/2611.34635)
