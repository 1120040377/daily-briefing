## 今日最值得知道

Google 的 Workspace 官方入口与 Anthropic 的 MCP 更新，正把 Agent 接入扩展到权限、流程知识和后台任务。新研究进一步比较了日常任务的交付质量，以及前沿模型搭配小模型的费用和时延，提示选型要同时验收完成率、成本与等待时间。

### Workspace 要求 Agent 经官方入口接入，迁移时间表已公布
<!-- news: agents -->

Google 宣布 Workspace MCP 与 CLI 正式可用，覆盖 Gmail、Drive、文档和日历等服务。公告称，Agent 需改经官方 MCP 或 CLI 接入，2027 年 2 月 1 日开始技术强制；外部 Agent 还需专用 OAuth 客户端身份。新附录限制将获取的数据用于训练、微调或评测集，并要求断开访问后删除所获用户数据及技术信息。**判断**　企业集成需重审入口、授权与数据生命周期。部分敏感文件访问限制仍属即将推出，不能把路线图当成已生效保护。

Yulie Kwon Kim（Google Workspace 产品副总裁） · 2026-11-24（首发；技术执行日期另见正文） · [公告](https://workspace.google.com/blog/product-announcements/built-for-trust-and-control-new-ai-agent-protections-and-developer-tools-in-google-workspace) · [附录原文](https://workspace.google.com/terms/ai-tools/)

### 本次新增 · Claude 让 MCP 服务同步提供技能与后台任务
<!-- news: agents -->

Anthropic 将 Skills over MCP 作为公测开放：服务端可随工具发布工作流指导，Claude 按需加载，指导也随服务器更新。Tasks 支持后台执行后取回结果，Elicitation 支持执行中向用户收集输入或确认；两者已对 Pro、Max、Ultra 正式开放，Team、Enterprise 正在逐步推出。Skills 的 Enterprise 支持和文件上传仍待上线。**判断**　工具集成可把业务流程知识与动作接口共同维护，接入验收应分别测试客户端开放范围、异步续接和确认流程。

Anthropic · 2026-11-24（首发，源站日期） · [发布说明与开放范围](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)

### Decider v2 把工具选择和路由变成单次前向评分
<!-- news: models -->

Strands 发布五个基于 Gemma 4 的 Decider v2 模型，覆盖 E2B 至 31B，以 Apache 2.0 开放权重。模型对给定选项一次性输出概率，可用于工具选择、模型路由和结果判定；新版改为直接读取选项 token 分数，并复用双向编码的共享上下文。文本之外，它也能对图像和视频任务作判断。官方说明，发布检查点已在留出问题上做温度校准。**判断**　选项明确且调用频繁的环节可独立评测决策模型，比较完整链路的成本与误判；通用校准分数仍需在实际任务分布上复核。

Sungyeon Kim 等／Strands Agents · 2026-11-23（首发，源站日期；重要遗漏补入） · [架构、训练与评测](https://strandsagents.com/blog/introducing-strands-decider-v2/)

### iFood 用统一远程执行层服务逾一万五千个代码仓库
<!-- news: industry -->

OpenAI 发布 iFood 平台案例：团队以内部 API 启动隔离沙箱中的编程任务，前后用确定性步骤完成环境准备和合并请求交付，中间由 GPT-5.6 Luna 执行。官方案例称已完成逾 2.5 万次运行，平均每次推理成本 0.04 美元，并用结构化输出归类结果。**判断**　规模化采用值得先解决共享运行环境和异步交付，再衡量任务质量。该数字来自客户案例，未给统一任务难度与观测周期，也不能视作包含沙箱、维护和人工复核的总成本。

Victor Coelho（iFood 高级软件工程师）／OpenAI · 2026-11-24（案例首发） · [原文](https://openai.com/business/customer-stories/ifood/)

### 本次新增 · ShellBench 将日常任务的完成度与安全要求一并验收
<!-- news: research -->

ShellBench 从用户请求衍生 100 项日常任务，比较 12 个模型、五种框架及三档推理强度，共运行 53,100 次。作者报告，GPT-6.1 Sol 与 GPT-6 Astra 的单次通过率为 61.4% 和 62.5%，按轨迹 token 及标价估算每次成本为 0.19 和 1.10 美元。**判断**　选型应检验便宜配置能否达到相近交付质量，而非只选最高分。这是 arXiv 预印本；90 项任务依赖模型裁判，成本含缓存启发式估计，不能把细小差距当成稳定领先。

### 本次新增 · Delegent 把查找与测试委派给小模型，减少前沿模型账单
<!-- news: research -->

Delegent 让前沿模型继续规划和改码，将查找、测试等子任务交给小模型，再仅取回报告。作者用 GPT-6.1 Sol 搭配 Qwen3.8-27B-FP8，在 50 项 DeepSWE 任务中与单模型基线同样解决 29 项；前沿 API 每任务均费从 2.11 降至 0.70 美元，将小模型按论文采用的 API 标价计入后约 0.81 美元。**判断**　混合模型值得按任务试验，账单和时延需共同验收。这是 arXiv 预印本的小样本结果；同组任务中位耗时从 25 增至 38 分钟，不能解释为整体工作更快。

Lingwei Gu、Jimmy Lin（滑铁卢大学） · 2026-11-24 18:34 UTC 首次提交（上海时间 11 月 25 日）；11 月 25 日列表公布，仅 v1 · [方法、费用口径与局限](https://arxiv.org/html/2611.33098v1) · [版本记录](https://arxiv.org/abs/2611.33098)

### Preflight 按应用实际调用路径验证依赖，而非只检查导入
<!-- news: research -->

Preflight 从 Python 应用提取依赖符号，由模型生成函数级探针，再以确定性校验、受限执行和版本行为对照验证。作者在 Ultralytics、ctx 两个事件中，用函数级探针均观察到恶意行为，仅导入的对照均未发现；另有 100 个良性包的已测工作负载未出现误报。**判断**　供应链验收应覆盖真实调用入口，不能将“未触发”解释为包整体安全。这是 arXiv 预印本的作者自报；动态分支可能漏测，实验也未证明模型探针优于具备同等 API 知识的确定性函数探针。

Yaman Jandali、Nojan Sheybani、Farinaz Koushanfar、Tara Javidi（加州大学圣迭戈分校） · 2026-11-23 17:50 UTC 首次提交（上海时间 11 月 24 日）；11 月 24 日列表公布，仅 v1 · [方法与局限](https://arxiv.org/html/2611.31110v1) · [版本记录](https://arxiv.org/abs/2611.31110)

### Meta Muse 扩展到英国，关键操作仍需用户批准
<!-- news: agents -->

Meta 将个人 Agent Muse 开放给英国 18 岁以上用户，覆盖手机应用、网页和 WhatsApp，提供免费使用及额外用量订阅。官方称，每个 Muse 使用独立云端虚拟电脑，可在关闭应用后继续处理任务；用户决定连接哪些服务，发送邮件或购买前需要批准，并可关闭将交互用于训练的设置。**判断**　消费级 Agent 正从回答扩展到持续执行，后续应观察授权撤销、任务恢复与错误操作的处理效果；发布材料尚不能证明跨服务任务的完成率。

Meta · 2026-11-23（首发及英国开放；11 月 24 日更新） · [英国发布公告](https://about.fb.com/news/2026/11/introducing-muse-in-the-uk-a-personal-ai-agent-you-control/)
