## 今日最值得知道

ChatGPT Wallet 开始逐笔授权试点，llama.cpp 与 ggml 进入 1.0。IBM 发布 Granite 安全预览，测试把外部资料和可执行指令分开训练的效果。四家非营利组织向旧金山法院请求限制五家公司的前沿 AI 研发。

### ChatGPT Wallet 开始试点，每笔 Agent 付款都由用户批准

OpenAI 在 Dots 中逐步开放 ChatGPT Wallet，首批面向美国年满 18 岁、持符合条件的美国发行银行卡的 Pro 用户。用户每次先核对商品、总价和所选卡，再通过面容或指纹等安全检查批准。OpenAI 称，支付网络随后提供代替真实卡信息的令牌，商家继续负责履约、退货和客服。**判断**　能否扩大使用范围，还要看商家风控能否识别合法的 Agent 交易，以及试点中有多少订单遭到误拒或取消。

OpenAI · 2026-11-13（美国公告日期） · [产品公告](https://openai.com/index/introducing-chatgpt-wallet/)

### llama.cpp 和 ggml 进入 1.0，接口破坏性变更将升主版本

ggml-org 同步发布推理库 llama.cpp 和张量库 ggml 的 1.0.0，承诺公开 C 接口及二进制兼容性发生破坏性变化时提升主版本，向后兼容的新功能和模型支持走次版本。首个 1.0 版已移除 35 个弃用函数，服务端新增语音合成接口。**判断**　版本规则便于下游决定何时升级。已有集成跨入 1.0 时，仍值得用现有调用编译一遍，并在目标硬件上验证模型加载和生成。

ggml-org · 2026-11-13 · [维护团队说明](https://huggingface.co/blog/ggml-org/llama-cpp-v1) · [版本记录](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0)

### 本次新增 · Granite 预览版把指令与外部数据分开训练

IBM 发布 Granite 4.1 的 3B 和 8B 实验预览，采用 LLMON 标记语言。执行块指定要遵循的指令及其输入，模型在后训练中学习把检索文档和工具返回内容当作数据。IBM 自测显示，8B 预览版在 OPI 静态间接提示注入基准上的攻击成功率为 0.02%，同规模常规 Instruct 版为 96.3%。**判断**　这适合纳入检索和工具调用的安全测试。结果来自同一模型家族，仍需单独测试多轮自适应攻击。

IBM Granite 团队 · 2026-11-12 · [发布说明](https://huggingface.co/blog/ibm-granite/llmon-an-llm-native-markup-language-now-in-granite) · [技术论文表 2](https://arxiv.org/pdf/2610.38120)

### 本次新增 · 四家非营利组织请求法院限制五家公司的前沿 AI 研发

Public Citizen 等四家组织向加利福尼亚州旧金山高等法院起诉 Anthropic、Google、Meta、OpenAI 和 SpaceX Super Intelligence。原告援引加州《不正当竞争法》，请求立即禁止被告研发或部署能力超过起诉当日各自最强系统的 AI，并禁止用 AI 自主研发更强系统。诉状中的风险指控和禁令范围均为原告主张。**判断**　后续要看法院是否发出禁令，以及如何界定和衡量“更强”。

### 检索问答实验发现，模型可以引用支持答案的资料，却沿用记忆里的数字

Tanzeel Abbas 等在 ASQA 问答中替换检索文档标题和正文里的目标数字，并排除问题仍含原值的样本。作者报告，在可判定来源的可引用陈述中，Qwen2.5-7B 有 8.2%、Llama 3.1-8B 有 15.7% 仍给出原值，被归为来自模型记忆。判断引文是否支持答案的基线接近随机识别；约两成记录无法判定来源。**判断**　对需要审计的问答，值得增加替换证据后重问的测试。该比例只适用于论文所测模型和数字陈述。

Tanzeel Abbas 等 · arXiv 预印本 · 2026-11-13（北京时间首次提交，arXiv 公布于 11-13） · [论文记录](https://arxiv.org/abs/2611.17161) · [全文](https://arxiv.org/html/2611.17161v1)

### Agent 能找到更强的半监督方案，挑中它仍需要可靠反馈

AgentSSL 让机器学习工程 Agent 在少量标注下反复编写、运行和修改半监督学习程序。作者在六个图像分类数据集上各测试两种标注规模，按测试结果事后选取最佳候选时，12 种设置有 8 种超过最强的人工调优半监督基线。实际选型若依靠噪声较大的验证信号或无标签指标，可能错过强方案。**判断**　标注预算有限时，值得留一部分标签专门比较候选方案，并把选型和最终评估分开。

Ethan Lin 等 · arXiv 预印本 · 2026-11-13（北京时间首次提交，arXiv 公布于 11-13） · [论文记录](https://arxiv.org/abs/2611.17323) · [全文](https://arxiv.org/html/2611.17323v1)

### ElevenLabs 扩大与 NVIDIA 的合作，把语音 Agent 带入政务自管环境

ElevenLabs 宣布 Nemotron 3.5 Super VL 已接入 ElevenAgents，并计划在现有 Blackwell Ultra 系统之外增配 15 兆瓦 Vera Rubin 算力容量。公司称，波兰国家电子健康平台的电话 Agent 使用其语音模型，在政府基础设施内处理音频，为只有座机的患者提供预约提醒和改期协助。波兰卫生部此前已确认电话提醒自 10 月起启用。**判断**　这项合作的实际效果可看改期成功率、失约率和人工转接率。

### Mirendil 获 10 亿美元 A 轮融资，科研 Agent 仍处私测

Mirendil 宣布完成 10 亿美元 A 轮融资，由 Kleiner Perkins 与 Clearlake Capital 领投，Google 参投。其科研工具 Lor 仍为私测，可让多个 Agent 并行写代码、运行实验。公司在 10 月披露，单名研究员借助 Agent 用约三个半月预训练 Mirendil-Base，计算相关支出低于 1,000 万美元，包含试验、数据处理和 Agent 的 token 开销。**判断**　这笔融资之后值得跟踪的，是外部团队能否在自己的任务上复现工期与成本。
