## 今日最值得知道

Qwen4-Max 开放限时预览，旧客户端要复查推理与正文共享的输出上限。MiniMax H3-Image 发布权重，自托管选型要核对下载体积和许可范围。AlphaProof Code 与 ReTrace 分别提供了用 Agent 生成机器码证明、用代码执行固定流程的实证。

### 本次新增 · Qwen4-Max 开放限时预览，推理与正文共用输出预算

阿里云在北京时间 11 月 11 日 10:00 开放 Qwen4-Max-Preview，Token Plan 可调用至 11 月 25 日 24:00，届时该预览版本下线。官方文档列出百万 token 上下文、图像与视频输入和工具调用。兼容 OpenAI 的 Chat Completions 接口中，`max_tokens` 和 `max_completion_tokens` 都限制推理和正文的合计长度。**判断**　迁移长任务时，优先测输出截断、工具结果和预览结束后的回退路径。

来源：[QwenCloud 发布记录](https://docs.qwencloud.com/changelog/models)、[接入与接口说明](https://docs.qwencloud.com/developer-guides/getting-started/latest-model)，2026-11-11。

### Gemini 4 Carbon 扩大开放，促销价格与推理成本须分开看

Google 在 10 月 28 日向部分网络安全防守方先行开放后，本次将 Carbon 提供给付费开发者和企业，并向 AI Ultra 用户逐步推出。官方列出的 API 导入价为每百万输入／输出 token 2／10 美元，11 月 30 日优惠结束后为 4／20 美元；Antigravity 的 /swarm 仍是预览。**判断**：复杂调试和长任务可重新做同预算验收。模型卡明确提示可能幻觉、缓慢或超时，高推理档也可能消耗更多 token；低单价不能直接推出单任务更便宜。此次新增是接入范围扩大，不是模型首次公布。

来源：[Google 发布公告](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)、[Google DeepMind 模型卡](https://deepmind.google/models/model-cards/gemini-4-carbon/)，Koray Kavukcuoglu，2026-11-10。

### ChatGPT 增加商家资料和专属 Agent，认领不保证推荐排名

OpenAI 推出 Businesses in ChatGPT 测试版，合格企业可经 Business Hub 验证并维护资料、上传含价格与库存的商品数据，查看提及、点击和发现主题的聚合指标。Business Agents 先面向美国合格电商与在线服务企业，其对话单独标识，与原聊天及 ChatGPT 独立回答分开。官方称不会向商家分享用户对话。**判断**：企业可关注商品资料如何进入对话式发现与咨询流程；认领不保证更高排名或销量，聚合数据也受最低交互量门槛限制。接入时应把商家陈述、广告和独立比较分别验收。

来源：[OpenAI 产品公告](https://openai.com/index/introducing-businesses-chatgpt/)、[资格与功能说明](https://openai.com/business/businesses-in-chatgpt/)，2026-11-10。

### 本次新增 · AlphaProof Code 把 Signal 协议验证推进到机器码

Google DeepMind 将未经改写的 libsignal 编译为 AArch64 Linux 机器码，由专家审核安全规约、Agent 生成证明，再由 Lean 内核校验。报告称，验证覆盖单聊握手和棘轮的前向保密等性质，两处复现的旧漏洞也被证明违反规约。结论依赖对密码原语的假设，群聊与服务端在范围之外。**判断**　这为关键组件提供了可复用的验收路径，下一步看版本迭代后能否低成本重验。

来源：[Google DeepMind 公告](https://deepmind.google/blog/introducing-alphaproof-code/)、[Swarat Chaudhuri 等技术报告](https://deepmind.google/documents/36/Formal_Verification_of_Signal_4.pdf)，2026-11-10。

### 本次新增 · MiniMax H3-Image 发布权重，部署前要核对资源与许可

MiniMax 公布 H3-Image，统一文生图和参考图编辑，支持最多 16 张参考图。官方模型卡称，蒸馏后六步采样可直接生成 4096×4096 方图，主模型下载体积约 68.65 GB。社区许可列出适用地区，对向第三方提供托管服务等情况要求事先书面授权。**判断**　评估自托管时，可按同分辨率比较端到端延迟、显存峰值与多图编辑一致性。

来源：[MiniMax 公告](https://www.minimax.io/blog/minimax-h3-image)、[模型卡与许可入口](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image)，2026-11-11 公告，社区许可将模型发布日期标为 11 月 10 日。

### NVIDIA 将 Agent 策略控制、环境恢复和推理扩容一起推进

NVIDIA 宣布向 CNCF 贡献 OpenShell，并参与 Google 发起的 Agent Substrate：前者用确定性策略约束 Agent 的工具、推理服务和工作负载，后者保留环境、空闲时释放算力。同期推出的 Snapshot 通过检查点恢复推理副本。官方转述设计伙伴 Crusoe 的测试：HGX B300 上 GLM-5.3 就绪时间由约八分钟降至 31 秒。**判断**：生产平台可分别验收权限执行、环境恢复和扩容等待。该数字来自特定伙伴负载，不是通用服务承诺；进入 Sandbox 也不等于完成安全认证。NVKE、NVKR 目前为公开预览。

来源：[NVIDIA 原始公告](https://blogs.nvidia.com/blog/open-source-openshell-infrastructure/)，Warren Barkley，2026-11-10。

### MKA 把图纸、表格和最终交付物一起纳入 Agent 评测

Google DeepMind 与 Artificial Analysis 发布 MKA，覆盖十类行业、83 种职业的 200 项任务，统一使用 Stirrup 框架。技术报告中，四个模型的最高总体加权准则满足率为 73.3%，不是整项任务成功率；前三名在较难准则上的差异无统计显著性。**判断**：企业助手验收可增加跨文件视觉证据和最终文件内部结构检查。每模型每题仅跑一次、裁判也仅评一次，区间不含运行波动；约 96% 人机一致率只来自 50 项任务的高权重检查，不能理解为所有格式和行业都同样可靠。

来源：[Google DeepMind 发布说明](https://blog.google/innovation-and-ai/models-and-research/gemini-models/multimodal-knowledge-agent-benchmark/)、[Anima Singh 等技术报告](https://storage.googleapis.com/deepmind-media/papers/mka_tech_paper.pdf)，2026-11-10。

### 本次新增 · ReTrace 把重复流程编译成无需模型逐步规划的代码

Kaiyuan Hou 等人从标准流程和 Agent 的工具调用及理由中提取分支规则，再生成可执行代码。作者在模拟电信客服的 τ²-bench 上报告，平均每题从原 Agent 的 170 秒降至 1.3 秒，成功率从 80.6% 降至 75.8%。私有企业数据中，平均耗时从 153 秒升至 163 秒。**判断**　适合优先试验高频、分支稳定的流程，验收应覆盖少见分支和实际工具结果。

来源：[arXiv 预印本 2611.14492](https://arxiv.org/abs/2611.14492)、[方法、实验与局限](https://arxiv.org/html/2611.14492v1)，2026-11-10 UTC 首次提交（北京时间 11 月 11 日），11 月 11 日列表公布，当前为 v1。
