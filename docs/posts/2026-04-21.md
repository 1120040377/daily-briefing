## AI 资讯

**1. Claude Opus 4.7 正式发布，编码与视觉能力全面跃升**（发布日期：2026-04-16）

Anthropic 于 4 月 16 日正式发布 Claude Opus 4.7，成为其目前最强公开模型。视觉分辨率从 1,568px 提升至 2,576px（约 3.75MP），编码基准大幅改进：SWE-bench Verified 达 87.6%（前代 80.8%），CursorBench 达 70%（前代 58%），GPQA Diamond 科学推理得分 94.2%。新增 `xhigh` 努力级别与 Task Budgets（Beta），给开发者提供更精细的质/速/价控制。定价与前代一致，$5/$25 per million tokens，但新分词器会使 token 用量增加约 35%。

🔗 [GitHub Changelog - Claude Opus 4.7 GA](https://github.blog/changelog/2026-04-16-claude-opus-4-7-is-generally-available/) | [Claude API Docs](https://platform.claude.com/docs/en/about-claude/models/whats-new-claude-4-7)

> 💡 **AI 点评：** Opus 4.7 在 SWE-bench Pro 上单版本提升 10.9 个百分点，对 AI 编码 Agent 赛道影响极大。开发者应注意新分词器导致的 token 消耗增加，现有预算测算需要重新调整；对于高频大上下文场景，建议先用 Claude Code `/ultrareview` 命令评估升级收益再决策。

🔗 [Vite 官方博客](https://vite.dev/blog/announcing-vite8) | [VoidZero 公告](https://voidzero.dev/posts/announcing-vite-8-beta)

> 💡 **AI 点评：** Vite 8 是近年来前端工具链最重要的架构升级。对于中大型项目（构建时间 > 30s），升级收益尤为显著，建议通过 `vite migrate` 评估兼容性后尽快升级。对于使用自定义 Rollup 插件的团队，提前验证插件兼容性是关键步骤。
