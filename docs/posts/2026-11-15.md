## 今日最值得知道

Poppy 1.0 让个人 Agent 到访商家时先确认身份和权限，Google 开放多 Agent 工程工作流。CapLite 预印本用固定规则限制 Agent 写入，实验也测出了任务完成率的损失。PostgreSQL 修复 52 个安全漏洞，14 分支结束维护。

### Poppy 1.0 让商家先确认个人 Agent 的身份和权限

Sierra 发布 Personal Agent Protocol 1.0。Agent 可以通过商家公开的入口发现网站、API 和客服 Agent，再用 OAuth 获取用户授予的权限。Sierra 称，Meta 的 Muse 已默认查找 Poppy，Shopify 店铺会自动发布入口文件。Poppy 处理身份和授权，商品检索、购物车和结账仍走 UCP。**判断**　商家接入时值得专门测试授权撤回后，Agent 能否继续访问历史订单或发起改动。

Sierra · 2026-11-13 · [发布公告](https://sierra.ai/blog/releasing-poppy) · [协议和实施入口](https://personalagentprotocol.org/)

### Google 开放多 Agent 工程工作流，用快速测试筛选 TPU 内核

Google Research 副总裁 Vahab Mirrokni 宣布，外部开发者和研究者可使用 Antigravity 的团队协作工作流。在 TPU 优化案例中，Google 称，四个 Agent 构建约 23 秒的代理测试，并定期用耗时 7–32 分钟的实机评估校验排序。最终在七个已手工优化的 Pallas 推理内核上，几何平均加速为 2.99 倍。**判断**　这套方法能否迁移，取决于快速测试能否持续挑出实机表现较好的候选。

Vahab Mirrokni（Google Research） · 2026-11-13 · [研究与开放说明](https://research.google/blog/advancing-science-engineering-with-antigravitys-teamwork-feature/)

### SGLang 进入 NVIDIA 认证推理微服务，跨硬件路线由联盟协调

LMSYS 在 11 月 12 日宣布成立 SGLang 联盟，创始成员包括 NVIDIA、AMD、Intel、Google 和 Meta，成员将与维护者共同制定路线。次日，NVIDIA NIM 与 SGLang 团队宣布，SGLang 已为 NVIDIA NIM Certified 微服务提供推理后端，NIM 提供验证过的容器和配置。**判断**　企业可以先按模型和 GPU 组合查看支持矩阵，再用自己的请求分布验收吞吐和延迟。

LMSYS、NVIDIA NIM 与 SGLang 团队 · 2026-11-12 至 11-13（美国公告日期） · [联盟公告](https://www.lmsys.org/blog/2026-11-12-sglang-consortium/) · [NIM 集成说明](https://www.lmsys.org/blog/2026-11-13-sglang-nvidia-nim)

### 本次新增 · CapLite 用固定规则检查 Agent 写入，安全性与任务完成率需一起看

Zimo Xu 等让程序按工具接口和用户请求核对收件人等敏感参数，再决定是否放行写入。在 AgentDojo 的 15 个开源权重模型测试中，作者报告，主实验 13,935 次工具目标攻击均未成功，无防护组的攻击成功率为 16.66%。受攻击时的任务完成率也从 50.2% 降到 29.0%。**判断**　部署时应同时测越权写入与误拦截。该模拟结果只覆盖所测攻击和工具，最终回答仍可能受注入影响。

Zimo Xu 等 · arXiv 预印本 · 2026-11-13（北京时间首次提交，11-13 公布） · [论文记录](https://arxiv.org/abs/2611.17115) · [全文](https://arxiv.org/html/2611.17115v1)

### 本次新增 · PostgreSQL 修复 52 个安全漏洞，14 分支结束维护

PostgreSQL 项目发布 18.7、17.12、16.16、15.20 和 14.25。其中 CVE-2026-6460 可让有权创建对象的用户以数据库服务进程的系统账户执行代码。18.7 发布说明写明，要让复合类型检查提供完整保护，需重新编译 C 扩展，部分扩展还要改源码。14.25 是 14 分支最后一次更新。**判断**　升级窗口应同时安排扩展测试，仍在 14 分支上的团队还需要规划主版本迁移。

PostgreSQL 全球开发组 · 2026-11-12 · [发布公告](https://www.postgresql.org/about/news/postgresql-187-1712-1616-1520-1425-and-19-rc-2-released-3442/) · [18.7 发布说明](https://www.postgresql.org/docs/release/18.7/)

### 数据中心供电模拟显示，通电工期可能改写成本排序

Alex C. Newkirk 等在同等供电可靠性下，比较美国本土的并网、离网天然气和两类光储方案。计入等待投产损失的算力价值后，直流耦合光储在 85% 的模拟地点成本最低。若假设燃气轮机可在 36 个月内投运，该比例降至 55%。**判断**　比较项目时应同时估算电价和等待成本。论文用发电侧排队时间近似用电侧并网工期，实际选址需要项目级数据。

Alex C. Newkirk 等 · arXiv 预印本 · 2026-11-13（北京时间首次提交，11-13 公布） · [论文记录](https://arxiv.org/abs/2611.17098) · [全文](https://arxiv.org/html/2611.17098v1)

### 本次新增 · 地图条件变化后，地理 Agent 的成功率明显下降

LiveGeo 在六座真实城市的地理结构上模拟道路、地点和事件变化，保留状态记录供复核。作者报告，九个模型在 149 道配对任务上，静态环境平均成功率为 19.1%，仅任务相关条件变化时降到 5.7%，全环境可变时为 4.0%。一些 Agent 发现变化后仍未改对计划。**判断**　验收行程类 Agent 时，应分别测它是否发现变化、是否正确重排。数字来自模拟环境。

Pengcheng Zhou 等 · arXiv 预印本 · 2026-11-13（北京时间首次提交，11-13 公布） · [论文记录](https://arxiv.org/abs/2611.17267) · [全文](https://arxiv.org/html/2611.17267v1)

### Helen Toner 主张把前沿模型的安全门槛前移到训练前

乔治城大学安全与新兴技术中心执行主任、OpenAI 前董事 Helen Toner 在 Decoder 访谈中说，对最先进模型，实验室在启动训练和决定发布前，都应对风险评估和缓解措施有足够把握。她认为，能达到安全门槛的研发可继续推进，达不到就需要更多时间，并区分前沿训练与日常部署实验。这是个人政策主张。**判断**　方案能否执行，取决于安全证据能否由外部复核。

Helen Toner · 2026-11-14（访谈发布） · [原始访谈](https://www.theverge.com/podcast/1032907/helen-toner-openai-cset-ai-safety-policy-interview) · [研究机构简介](https://cset.georgetown.edu/staff/helen-toner/)
